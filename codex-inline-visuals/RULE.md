## Inline interactive visuals

Codex Desktop can display interactive HTML directly in the conversation, including
Pele diagrams. For inline charts, diagrams or clickable explainers, load
`~/.agents/skills/codex-inline-visuals/SKILL.md` (or its Codex skills entry), then
the complete current bundled Visualize skill. If missing from the catalog, locate
it under the current Codex home's `plugins/cache/openai-bundled/visualize/`.
Use the native `visualize` response reference; T3's HTML tools are not required.
