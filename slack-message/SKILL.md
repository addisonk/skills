---
name: slack-message
description: Use before every Slack post — slack_send_message, slack_send_message_draft, slack_schedule_message, thread replies and DMs — and whenever drafting, rewriting or editing Slack copy, including messages sent on the user's behalf.
---

Write like a coworker: casual, relaxed, and direct. Use contractions and everyday words. Cut filler, repetition, and corporate language.

- Lead with the point or request. Add only essential context.
- Default to 1–3 short sentences. For multiple items, keep labels and shorten explanations to a few words, preserving the question or choice.
  Example: **Lawyer review:** Get one before launch, or publish as is?
- Preserve the writer’s voice, facts, and uncertainty. Include asks, owners, and deadlines only when supplied.
- Draft when asked to write; send or update when explicitly requested. Use the intended recipient, channel, and thread. Ask only if the destination or message is unclear.
- For drafts, return only ready-to-paste copy. After sending or updating, confirm with the message link. Add no agent signature or authorship footer.
