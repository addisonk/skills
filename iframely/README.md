# Iframely skill

Hosted API integration, responsive embeds, URL metadata and troubleshooting.

Install the public skill:

```sh
npx skills add addisonk/skills --skill iframely
```

Start with SKILL.md. Official documentation snapshots and an authored troubleshooting guide are bundled under references/. SOURCES.json records retrieval date, page coverage, hashes and the open-source repository revision.

The snapshot covers all 41 URLs in the official developer/publisher docs sitemap plus the introduction. Help-center articles, updates, marketing pages and external integration documentation are not included. Consult upstream sources for current provider and plan details.

Documentation source: https://iframely.com/llms-full.txt and https://iframely.com/llms.txt. Open-source references: https://github.com/itteco/iframely. Upstream website documentation remains attributed to Iframely; the MIT license in references/open-source applies to the repository material.
