# Iframely

> Iframely connects products and publishers through rich media, embeds, previews and URL data. Send any URL to the API and get back responsive embed code, oEmbed or unified URL metadata for 1900+ supported providers.

Every docs page is also available as markdown: append `.md` to its URL (for example https://iframely.com/docs/iframely-api.md).
The complete documentation in a single file: https://iframely.com/llms-full.txt.

## Introduction

- [Getting started](https://iframely.com/docs.md): Iframely gives you responsive embeds via oEmbed, Twitter Cards and Open Graph parsers
- [What URLs to send](https://iframely.com/docs/providers.md): Send us as many URLs as you like. You won't be billed for poor results
- [Third-party media](https://iframely.com/docs/embeds.md): Send us as many URLs as you like. You won't be billed for poor results
- [Hosted iFrames](https://iframely.com/docs/iframes.md): Iframely can wrap raw html embed codes into hosted iFrames for security, speed and required fallbacks
- [API keys](https://iframely.com/docs/allow-origins.md): Control origins that have access to your Iframely account, activate CORS and CSP

## API endpoints

- [oEmbed API](https://iframely.com/docs/oembed-api.md): oEmbed API for Responsive Web Embeds. Open-Source or hosted
- [Iframely API](https://iframely.com/docs/iframely-api.md): Mighty API for Responsive Web Embeds. Based on oEmbed, Open Graph, Twitter Cards
- [Embed.js](https://iframely.com/docs/embedjs.md): Generate responsive embed codes for media players, rich other embeds and summary cards
- [API parameters](https://iframely.com/docs/parameters.md): Configure parameters in your settings or send with every API call
- [Result codes](https://iframely.com/docs/result-codes.md): Here's the error codes you might receive from Iframely
- [Per-use options](https://iframely.com/docs/options.md): Let your users customize individual rich media embeds for their posts, right in the text editor

## Interactives

- [Autoplay](https://iframely.com/docs/autoplay.md): Iframely lets you safely autoplay videos when user sees them

## Content delivery

- [Omit CSS](https://iframely.com/docs/omit-css.md): Use &omit_css=true to switch Iframely to use class names instead of inline CSS styles
